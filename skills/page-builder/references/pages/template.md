# Template Pages

## Shared Responsibility

Template pages let users discover, evaluate, preview, and use reusable starting points. The page must connect its preview to a real copy, customize, download, install, or create flow.

## Modes

- **Hub:** organize templates by task, format, platform, audience, or style with meaningful discovery controls.
- **Detail:** show the actual template, intended use, included parts, compatibility, rights, update state, and primary use flow.

## Boundaries

A Template is a reusable starting artifact. It is not automatically a programmatic SEO page, a generic Resource, or a marketing Landing page. If templates are generated from data at scale, the publishing system remains an upstream concern while Pagina owns each resulting page contract.

## Components And Verification

Grid, Card, Task Input, Carousel, Tabs, How-to, FAQ, Breadcrumb, CTA, and previews may apply. Verify filters, previews, source files, compatibility, licenses, pricing, versioning, copy/customize/download behavior, authentication transitions, empty states, related templates, metadata, and duplicate or thin variants.
